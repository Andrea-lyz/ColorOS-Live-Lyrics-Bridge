# D1 fix19：动态封面正式设置（切片 F）

日期：2026-10-04。只改 Bridge，AM 插件沿用 fix17。按方案 10.1 节把动态封面从 Debug 联调页搬到正式设置。

## 改动

### 设置与同步（独立配置域）

- 新增 `ArtworkDisplaySettings`：偏好 `lockscreen_lyrics_artwork`，字段为总开关、插件引用（组件、签名、协议主版本）、
  小卡片/大封面开关、保持亮屏、revision。默认关闭、两个位置开启、不保持亮屏。不进入 `LyricUiConfig`，也不用歌词样式轮询。
- App 每次更改都保存并发送 `ARTWORK_SETTINGS_CHANGED`（Bridge 签名权限保护）。SystemUI 收到后写入自己的副本，
  启动时读回，因此**重启 SystemUI 后自动恢复**，不再需要重新点联调按钮。
- 接收器由 SystemUI 侧动态封面运行时自己注册，不依赖歌词 DexKit 引导成功（原 Debug 广播挂在歌词设置接收器上）。
- 存储容错：字段缺失或类型错误时取默认值，组件或签名格式不合法时清空选择，损坏的存储只能让功能关闭，不会指向其他插件。
  插件引用只是引用，SystemUI 每次绑定前照旧校验组件、签名和协议。
- 仅改变显示位置或亮屏选项时保留正在运行的解码器；更换插件或开关总开关才重建。

### 正式设置页“动态封面”

主设置页新增独立卡片入口，副标题显示“已开启 · 插件名”“已开启 · 需要检查插件”或“未开启”。页面结构：

1. **状态卡**：向 SystemUI 查询实际运行状态，页面可见时每 3 秒刷新。显示正在播放、正在匹配/下载、
   等待锁屏播放、专辑无动态封面、未匹配（提示可在 AM 插件手动绑定）、插件来源未启用、网络暂不可用、
   所选插件仅用于测试、插件拒绝请求、无法连接插件、当前布局无法播放等。SystemUI 无响应时提示确认作用域并重启 SystemUI；
   设置尚未被 SystemUI 确认时显示“正在应用设置”；调试测试运行时显示其正在覆盖正式设置。
2. **显示**：启用动态封面、锁屏小卡片、大封面。首次打开总开关时，若未选插件先弹出选择；
   确认弹窗说明会向所选插件发送歌名、歌手、专辑和时长，不发送歌词、账号、设备标识或媒体 ID。
3. **封面来源**：当前插件与状态（已就绪、未安装/已停用/协议不支持、签名已变化需重新选择），
   “选择插件”（列出名称、包名、签名前缀）和“插件设置”。
4. **屏幕**：动态封面播放时保持屏幕常亮（fix18 的开关搬到这里）。

状态码只包含结果类别和原因，例如 `no_motion:confirmed_album_no_motion`，不含曲名或其他歌曲文本。
`ArtworkProviderClient` 现在会保留几类明确的拒绝原因（`provider_mode_mismatch`、`artwork_caller_denied`、
`provider_unavailable`、`provider_identity_changed`），其余仍为 `provider_or_asset_failed`；重试策略不变。

### 调试页与备份

- “动态封面 · 调试”页只保留 App 内预览和锁屏固定视频测试（本地测试插件）。“开启 AM 锁屏联调”和亮屏开关移到正式页。
  固定视频测试运行时临时覆盖正式设置，关闭测试或重启 SystemUI 后恢复。
- Bridge 配置备份新增动态封面域（可选）：未改动过动态封面设置时备份中不包含该域，旧版本仍可恢复；
  新版本可恢复不含该域的旧备份（视为默认关闭）。恢复后重新校验插件，未安装或签名变化时保持选择引用但关闭功能。
  恢复与重置会把动态封面设置同步到 SystemUI。

## 本地验证

- Bridge：736 项测试，0 失败，6 跳过。新增 `ArtworkDisplaySettingsTest`（默认值、生效条件、存储往返、损坏存储只会关闭、
  协议版本、会话保留判断、拒绝原因命名）与 `ArtworkSettingsStatusTest`（状态分类、备份域兼容）；备份契约测试补充动态封面域。
- Lint：0 errors / 48 warnings，变更文件未新增警告；新接收器沿用歌词设置接收器的签名权限与同一 Lint 抑制。

## 设备验证

1. 用户重启 SystemUI（新接收器需要新代码加载）。
2. 设置 → 动态封面：选择 AM 插件，打开总开关并确认说明。状态卡应变为“已开启，等待锁屏播放”。
3. 锁屏播放：小卡片和大封面出现动画，状态卡在页面内显示“正在播放动态封面”或最近结果。
4. 分别关闭小卡片、大封面，确认对应位置恢复静态封面且另一处不受影响；切换亮屏开关即时生效且视频不重启。
5. **重启 SystemUI 后不再操作**，锁屏应直接出现动画（持久化验证）。
6. 备份与恢复：复制备份 → 关闭动态封面 → 从剪贴板恢复，设置回到备份时状态。
7. 调试页开启固定视频测试时正式页显示“调试测试正在运行”，关闭测试后恢复正式设置。
