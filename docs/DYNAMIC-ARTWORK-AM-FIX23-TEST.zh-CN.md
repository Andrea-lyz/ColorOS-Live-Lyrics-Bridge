# D1 fix23：动态封面 Provider 界面重做

日期：2026-10-04。主要改 AM 插件的界面与资源；Bridge 只改设置页文案中对插件的称呼。匹配、下载、缓存和协议逻辑不变。

## 用户需求

“AM 插件”改名为“动态封面 Provider”；语言跟随系统，适配中文和英文；重做界面，多一些可视化效果；生成符合主题的应用图标。

## 改动

### 名称与语言

- 应用名：中文“动态封面 Provider”，英文“Dynamic Artwork Provider”。包名、服务与设置 Activity 类名不变，
  Bridge 中已保存的组件与签名选择继续有效；版本改为 0.2.0（versionCode 2）。
- 默认资源改为英文，中文放在 `values-zh`：任何中文系统显示中文，其他系统语言显示英文。
  增加 `locales_config`，Android 13 起可在系统“应用语言”中单独选择。
- Bridge 设置页与调试页中提到“AM 插件 / AM provider”的文案改为“动态封面 Provider / Dynamic Artwork Provider”。

### 主页（Bridge 中“Provider 设置”打开的同一页面）

- 顶部大封面：循环静音播放最近缓存的动态封面（点按切换下一个）；无缓存时显示缓慢流动的渐变动画。
  封面下方有柔光，来源关闭时动画褪色、柔光变暗；左下角显示“来源已启用/已关闭”，播放视频时右上角显示“动态”。
- 动态封面来源总开关：打开时先弹出说明（发送哪些信息、默认仅非计费网络），确认后才启用。
- 四个状态卡片：
  - 网络：类型与是否可下载，随网络变化实时更新，点按打开系统网络面板。
  - 查询市场：地区代码与本地化地区名，点按切换。
  - 缓存：已用空间与封面个数。
  - 手动绑定：绑定数量，点按进入绑定页。
- 匹配概览：最近请求的专辑按“已匹配 / 已绑定 / 无动态封面 / 未匹配 / 获取失败”画成环形图（展开动画）并列出数量；
  有未匹配或获取失败时提示可手动绑定。
- 动态封面缓存：渐变用量条（上限 256 MiB）、已缓存封面的缩略图横向列表（取视频帧），点按在顶部预览；“清除未使用的缓存”。
- 来源设置：允许计费网络下载、查询市场（常用地区列表或手动输入两字母代码）。
- 高级：脱敏诊断日志；Bridge 应用内预览授权（显示已授权 / 未授权 / 签名已变化 / 未安装，可授权或撤销）。
  撤销授权不再顺带关闭来源。锁屏由 SystemUI 按 UID 校验，不需要此授权。
- 所有开关即时生效，不再有“保存”按钮；市场修改从下一首歌起生效。

### 手动绑定页

- 两步卡片：①本地专辑（专辑名、可选歌手）②在 Apple Music 中查找（关键词或专辑链接）。
- 搜索结果显示专辑封面缩略图、年份、曲目数和 Explicit 标记；行内“绑定”按钮依次显示确认中和已绑定。
- 已有绑定：缩略图、本地专辑名、“仅限歌手”标签、对应的 Apple Music 专辑与市场；删除前确认。
- 最近请求的专辑：首字母色块和带颜色的结果标签，点按填入。
- 适配深色模式、全面屏与输入法弹出。

### 封面缩略图的网络范围

- 只在绑定页由用户发起搜索时，从 Apple 图片 CDN 加载搜索结果的封面。
  地址必须是 HTTPS、主机为 `is<数字>-ssl.mzstatic.com`，且不带端口、用户信息、查询参数或片段；单张上限 1 MB。
  锁屏服务的下载链路与域名白名单不变。
- 绑定成功时把该专辑封面存到本地缓存（`cacheDir/am-thumbs`），已有绑定列表只读本地文件，不联网；
  没有任何绑定引用的专辑封面在删除或替换绑定时一并删除。
- 粘贴专辑链接时，额外用 iTunes lookup 获取标题与封面，仅用于显示；失败时退回页面中的曲目信息。

### 图标

自适应图标：粉红到紫到靛蓝的渐变底，前方是带渐变播放符号的白色封面，后方是一帧半透明封面，左上角有星光点缀。
包含单色图层，支持 Android 13 起的主题图标。所有图形都在安全区内，圆形、方形和圆角方形遮罩下都完整。
