# ColorOS Live Lyrics Bridge v4.1.0

4.1 migrates the complete 12-Provider matrix to libxposed API 102 while preserving the native
`Provider -> player MediaSession lyricInfo -> ColorOS SystemUI -> optional Bridge` architecture.
Bridge remains scoped only to `system` and `com.android.systemui`.

## Highlights

- All 12 Providers use one modern entry, static scope, protective exception mode, and Remote
  Preferences for debug configuration.
- Every Provider is versioned `1.1.0`; Salt is `versionCode 6`, and the other 11 are
  `versionCode 2`.
- Bridge hardens controller/publication lifecycle, track identity, renderer fail-open behavior,
  OPlus action icon handling, cache ownership, accessibility, and diagnostic privacy.
- KuGou same-track ID enrichment no longer advances generation, and non-monotonic cold-start
  official lyrics are normalized from the same KRC while retaining production credits.
- KuWo first-track MediaSession/artwork completion is generation- and identity-bound.

## Compatibility and upgrade

The supported player matrix is unchanged from 4.0. Upgrade Bridge and the Providers you use from
the same 4.1.0 Release. 4.1 Providers require libxposed API 102; LSPosed 2.2.0 or newer is
recommended. Debug preferences start from the disabled Remote Preferences default, and Hot Reload
is not supported. Restart each affected player process after upgrading.

Rollback uses the official 4.0.0 Bridge and Provider packages. Application IDs and release signing
are unchanged; Android may require explicit version-downgrade installation.

## Validation

- API 102 migration: all 12 Provider modules passed source/resource/entry/scope/dependency and
  debug-matrix gates; 488 tests passed with no failures/errors/skips and exactly 12 debug APKs.
- User device regression: Wave A–E covered all 12 Providers and their supported profiles.
- Bridge: 503 tests passed with no failures/errors and six explicit skips; debug/release lint had no
  errors; the debug APK built successfully.
- Final regressions: the KuGou first lyric, KuWo first-track cover, and OPlus media action path were
  confirmed by the user.
- Formal RC/GA: 13 signed APKs and 16 assets are checked for R8, package/version, API 102 resources,
  scope, certificate, zipalign, forbidden DEX strings, inventory, and SHA-256.
