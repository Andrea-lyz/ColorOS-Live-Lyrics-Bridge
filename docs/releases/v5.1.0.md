## Known limitations

- Official Apple Music lyrics with a subscribed account are not device-verified. The no-subscription indication is inferred from lyric and account responses, not a direct entitlement check; a storefront or service problem could also cause it.
- The upstream Lyrico project is Apache-2.0. The separately maintained Lyrico-Plugins repository had no license metadata or license file when checked; do not attribute its code to an Apache-2.0 license without separate evidence.
- The user accepted RC1 without an itemized checklist. ColorOS 16 animation and official Apple Music lyrics using a subscribed account remain unverified on a device.
