## 用户可见变更

- **QQ 音乐媒体卡控制按钮错位修复**：不再为该播放器强制 OPlus Rule0 / 重新下发规则表，保留系统
  原生 action row；翻译按钮继续通过收藏槽原地替换。真机确认按钮顺序恢复、锁屏翻译按钮仍在。
- **翻译按钮合成动作兜底**：既无 `PlaybackState.CustomAction` 也无 OPlus heart 的播放器，由 Bridge 合成
  framework 同类型 SystemUI `MediaAction` 注入 Rule0（并置 `hasCustomAction`），点击仍在 Bridge 内处理。
- **歌词时钟平滑**：播放中 < 600 ms 的位置偏差按本地时钟修正处理，不再触发跳变/回退；状态切换与
  大跳变仍以宿主为准。
- **KuWo Provider 1.2.0 (3)**：只往宿主 metadata 追加 `lyricInfo`；删除联网补封面与 240px 重绘；
  封面通道与 Bitmap 实例保持宿主原样。其余 13 个 Provider 行为不变。

## ColorOS 17 适配计划

ColorOS 17 的 nolog 版本封锁 bootloader，无法解锁并建立模块运行环境，因此本项目不跟进 nolog
分支的更新与适配；主力机型一加 13 也尚未收到 ColorOS 17 nolog 版本，缺少可验证的设备条件。
ColorOS 17 适配将在 **ColorOS 17 正式版发布之后**启动：先核对 SystemUI 媒体/歌词实现与权限面
差异，再发布 Bridge 与 Provider 适配版本；在此之前现有 ColorOS 16 版本继续接收 bug 修复。
