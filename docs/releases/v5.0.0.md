## Release notes addendum, 2026-11-16

The published notes left out changes that reached `main` after v4.5.4 through PR #64 (`7d8365c`, `e99d493`) and the never-released Universal Provider 1.1.3 fixes (Providers `2ea9272`). `.github/release-notes/5.0.0.md` now also covers:
- ColorOS 17.0.1.x adaptation (runtime-signature translation action with the AOD icon, metadata replay gating, verified album-art field binding);
- the cover-glow palette fix on some devices, the two character-lift fixes and KuWo artwork colours bound to the media ID;
- the Universal Player Provider 1.1.4 matching, source-priority, negative-cache and cache-clearing fixes (previous public version 1.1.2).

The GitHub Release `v5.0.0` body and the LSP mirror `150-5.0.0` body (donation block kept) were edited to match; assets were not touched. The Providers Release `universal-provider-v1.1.4` body was corrected the same way. The release notes text embedded in the signed store catalog (revision 15) still carries the original wording until the next catalog revision.
