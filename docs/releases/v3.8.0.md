# ColorOS Live Lyrics Bridge v3.8.0

v3.8.0 完成本地酷我适配收尾：无需开启车载歌词模式即可提供完整歌词、翻译和稳定的锁屏歌词按钮；同时修复酷狗 Provider 的串曲与封面身份问题，并增加对后续 ColorOS/SystemUIPlugin 与酷我版本变化的结构兼容。

本版本还登记了 Halcyon 与 Flamingo 的原生 v4 Provider 接入。

完整发布说明见 [Bridge `.github/release-notes/3.8.0.md`](../../.github/release-notes/3.8.0.md)。全部 Provider 合集资产名为 `LyricProvider-All-v3.8.0.zip`。
