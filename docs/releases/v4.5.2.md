## User-visible changes
- Bridge release APKs are minified and resource-shrunk with R8. Debug builds stay unminified.
- Same SystemUI / SystemUIPlugin versionName and versionCode can differ internally. RUS map counts,
  the immersive album writer, C17 controller roles, `MediaInfo.albumArt`, the card spring running
  flag, and the metadata-changed entry are resolved from unique logs or types, with the reviewed
  letters as fallback.

## Release pipeline changes
- Bridge `release` sets `isMinifyEnabled` and `isShrinkResources` to true and applies
  `proguard-android-optimize.txt` plus `app/proguard-rules.pro`.
- DexKit JNI classes are kept by name. The libxposed `java_init.list` rule is unchanged.
