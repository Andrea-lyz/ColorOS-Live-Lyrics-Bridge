# ColorOS Live Lyrics Bridge v4.1.1

4.1.1 is a focused Bridge maintenance release. It keeps the 4.1 architecture: Bridge runs only in
`system` and `com.android.systemui`, while Providers publish standard `lyricInfo` through the
player's own MediaSession.

## Changes

- Preserve OPlus media-action identity and the original action list across repeated translation
  binding and settings changes.
- Restore the player's native action when the translation button is disabled or the current track is
  known to have no translation; keep transient track-change gaps fail-open.
- Apply the user-disabled setting during rebind and request a fresh media-action model after settings
  or lyric-model changes.
- Patch both OPlus action-rule maps used by the regular media card and Quick Settings.
- Include the device-validated `com.md3music.md3music` media-history/translation compatibility entry;
  MD3Music replaces desktop lyrics only while a translation is available and preserves favorite.

The 12 Provider modules are unchanged and use the metadata-only source tag `providers-v1.1.1`.

## Upgrade and rollback

Install the Bridge APK with libxposed API 102 and keep its scope limited to `system` and
`com.android.systemui`. Restart SystemUI after installation and restart the affected player after
translation-action setting changes. Use the matching Provider APKs from the 4.1.1 Release. Rollback
uses the published 4.1.0 Bridge and Provider packages.
