# ColorOS Live Lyrics Bridge v3.8.1

v3.8.1 修复酷我通知栏媒体卡片在播放数秒后封面被降级为纯色的问题：metadata 重发携带的 `1x1` 占位封面现在会在 SystemUI 封面查找点按严格同曲身份恢复为真实封面。同时为酷我 Provider 的歌词拉取增加有界重试：切歌时若酷我自身拉词因网络等原因失败，Provider 会按 2s/5s/10s 退避自动重试，避免小概率卡在大封面、必须手动暂停才恢复的问题。

本版本只调整 Bridge 的酷我封面恢复分支与酷我 Provider 的拉词重试，不改已冻结的锁屏歌词链路。

完整发布说明见 [Bridge `.github/release-notes/3.8.1.md`](../../.github/release-notes/3.8.1.md)。全部 Provider 合集资产名为 `LyricProvider-All-v3.8.1.zip`。
