# v4.2.1 发布台账

## 发布范围

- Bridge：`4.2.1` / versionCode `140`。
- Provider source：`main`，在 workflow metadata 阶段冻结完整 commit SHA。
- LSP tag：`140-4.2.1`。
- 矩阵：12 个专属 Provider、`universal-provider` 与 `player-readify`，共 14 个 Provider APK。
- 资产：Bridge + 14 Provider APK，共 15 APK；含 Provider ZIP、manifest、`SHA256SUMS`，共 18 项。

## 关键边界

Readify Provider 只进入 `com.readin.app`，从宿主已有 MediaSession 的 AI/Readium TTS
回调发布 `sentence-window-v1`。Bridge 继续只作用于 `system` 和
`com.android.systemui`，不进入播放器进程、不创建额外 MediaSession，也不恢复旧私有歌词通道。
