# ColorOS Live Lyrics Bridge v3.5.0

v3.5.0 把 v4 外部歌词协议补到可在长歌词场景稳定运行的形态：Bridge 与 Provider 各自新增并对齐了大小限制常量，Provider 侧加入逐行截短重试，`LyricInfoContract` 支持纯逐字歌词走完整流水线；这一版本同时收紧 `BridgePayloadGate` 的去重窗口并把 `LockscreenLyricsModule` 的渲染/时序逻辑拆到独立类，便于后续按层迭代。

完整发布说明、验证清单与 10 项 Release 资产见 GitHub Release 与 [Bridge `.github/release-notes/3.5.0.md`](../../.github/release-notes/3.5.0.md)。
