# Release v5.1.2 Ledger

Status: **In preparation.** Local branches only; nothing pushed, no RC, no tags.

## Release scope

- Bridge: 5.1.2, versionCode 153; Bridge tag `v5.1.2` and LSP tag `153-5.1.2`.
- Bridge-only dynamic artwork fixes:
  - tiered retry for transport, process and decoder failures (5 s / 30 s, at most 3 per song);
  - same-song metadata text drift (same media ID, duration within 3 s, card unchanged) keeps the accepted binding instead of stopping a playing motion cover;
  - detach watch for the C16 card and immersive mounts;
  - the live query reaches album bindings without a duration; incomplete identity is reported as `live_identity_incomplete`;
  - the diagnostics export carries the last artwork outcome.
- Bridge store: "install with another app" (PR #80, merged into `main` at `ded62413dcace81fb913e4fab5b48d06d7f09717`): after a download passes the content and identity checks, the card offers the system "open with" chooser for the cached APK through a FileProvider limited to the store download cache (read-only grant); a session still waiting for confirmation is finished as success when PackageManager already shows the expected version and signer. Debug builds were confirmed by the user on PHB110 and PJZ110 before merge.
- Bridge store: a plugin signed differently from the catalog entry now offers the normal download-and-install flow (PackageInstaller decides; a refusal shows the existing conflict message). The note reads "may fail" instead of "cannot". No uninstall or data wipe is offered, and such plugins are still not announced by the update reminder.
- Provider store updates in the same period (released independently from the Providers repository): Dynamic Artwork Provider 1.0.7 (versionCode 11; store release [run 44882016944](https://github.com/Andrea-lyz/ColorOS-Live-Lyrics-Providers/actions/runs/44882016944), public APK SHA-256 `5420e4db81e99b2260d539095126f91ea0269b45e07174d42be610d4e8c3016b`, release signer `ff38544b…36195`, 16 KB zipalign passed), Salt Player Provider 1.1.4 (`player-salt-v1.1.4`), Universal Player Provider 1.1.6 (`universal-provider-v1.1.6`).
- Providers `main` frozen at `aaacba017e54f46e500090560c3f1b8d98b57eb7` (Providers PR #25 merge; tag `artwork-provider-am-v1.0.7` peels to it).
- Bridge assets: one signed Bridge APK, `release-assets-v5.1.2.json` and `SHA256SUMS`.
