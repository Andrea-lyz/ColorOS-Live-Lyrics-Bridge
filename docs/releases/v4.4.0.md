## User-visible changes
- **Append-only lyricInfo**: LX, Poweramp, Apple Music, Metrolist, KuGou, NetEase and QQ Music
  write only `lyricInfo` into the host metadata object (provider-core `HostMetadataOverlay`);
  no metadata rebuild, no artwork redraw. KuWo moves onto the shared layer.
- **KuGou binding**: foreign candidates are kept; binding by file name, leading line or official
  lyric content removes the official-renderer flash on track switch and whole-song fallback.
- **KuGou identity and rows**: hyphenated names inside artist lists are no longer split;
  `lyric` is built from the same lines as `rawLyric`, removing the empty leading row.
- **Universal Player 1.1.0**: torn-metadata identity gate, coarse-clock line fallback, recent
  lyric history backfill.
- **Bridge line clock alignment** (`NativeLyricClockPolicy`): official current row and word fill
  share the Bridge clock; unresolved controller falls back to the monotonic guard only.
