## User-visible changes

- realme UI7 no longer flashes the official lyric renderer for about a second after a track change, lyric-page expansion, or screen wake.
- Settings receipts use a framework ResultReceiver proxy and no longer crash SystemUI while unmarshalling an R8-merged App subclass.
- UI7 lyric rows bind exact line spacing, scroll duration, and inactive-row scale fields.
- Character float-up rows no longer dip before becoming the live row.
- Track transitions publish a model, complete native dataset expectation, and renderer-cache reset together on the UI thread. The committed native list, row-binding cohort, and geometry must agree before a complete pixel batch is emitted, preventing isolated shared credits from the outgoing list.

## Implementation

- The native lyric cache accepts a display-only timed source when raw word timing is absent. Plain timed text builds a LINE_TIMED model; a later complete raw source replaces it with real word timing.
- Identity-bound complete models are retained only for a same-track, same-player refresh. Current-packet rendering handles explicit identity conflicts.
- Diagnostic state records model publication, clearing, retention, native line-timed takeover, handoff timeout, and render fallback without complete lyric text or raw stable media IDs.
- Complete ordered native time/text datasets establish render ownership. ColorOS 16 observes setLyrics and concrete adapter binds; ColorOS 17 reads ListAdapter.getCurrentList rather than treating an asynchronous update request as a commit.
- Real bind tokens fence stale/nested completion and competing position owners. Unchanged DiffUtil rows migrate only after the complete new list is authoritative. Dataset/model checks also guard geometry, prebind, readiness, cached/custom drawing and renderer-error fallback.
- A scoped parent draw transaction uses a temporary Canvas clip until the batch is coherent, then invalidates old/hidden holder display lists. It adds no fixed wait, View alpha/visibility change, or native animation/scroll override. RC2's standalone position heuristic is removed.
- Host Adapter discovery and bind selection use the host's structural method/type contract, preventing R8 from substituting the module's own obfuscated AndroidX class name into a cross-ClassLoader comparison.
