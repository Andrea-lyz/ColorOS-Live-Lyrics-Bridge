# v4.2.0 发布台账

## 发布范围

- Bridge：`4.2.0` / versionCode `139`。
- Provider source tag：`providers-v1.2.0`。
- LSP tag：`139-4.2.0`。
- 矩阵：12 个专属 Provider 加 `universal-provider 1.0.0 (1)`，共 13 个 Provider APK。
- 资产：Bridge + 13 Provider APK，共 14 APK；含 Provider ZIP、manifest、`SHA256SUMS`，共 17 项。

## 关键边界

通用播放器 Provider 只在 `system_server` 运行，用户在其设置 App 内选择目标包。Bridge 保持
`system`、`com.android.systemui` 两个 scope，不恢复播放器进程 Hook 或旧私有歌词通道。蓝牙/车载
歌词覆写标题与通用 Provider 不能同时启用；该已知限制及未完成真机场景以 Provider 回归矩阵为准。
