# ColorOS Live Lyrics Bridge v4.0.0

4.0 completes the native `lyricInfo` architecture: player-specific hooks are delivered by 12
independent Provider modules, while Bridge is limited to `system` and `com.android.systemui` for
generic rendering, AOD, translation controls, appearance, and compatibility enhancement.

## Major changes

- Removed the Bridge direct-v4 receiver/protocol, Provider registry, private source mapping, and
  player-process adapters.
- Added native one-pass lyric model assembly, indexed translation alignment, frame resolution, draw
  coordination, and structured diagnostics.
- Added independent lyric brightness/fading controls, updated presets and preview, immediate
  translation action feedback, and correct center/right scale pivots.
- Added complete Bridge configuration backup/restore and full reset.
- Opening-cleanup rules remain available but default to disabled.

## Provider suite

The coordinated release contains Salt, Cone, KuWo, LX, Poweramp, Metrolist, KuGou, QQ, NetEase,
Apple, Spotify, and QiShui Providers. Each publishes standard `MediaMetadata["lyricInfo"]`; ColorOS
SystemUI can consume it without Bridge, while Bridge adds optional generic enhancements.

Metrolist and Spotify currently have no translation. QQ Music HD, MusicFree, Gramophone, and
Symfonium are outside the 4.0 matrix. The former Flamingo v4-only route requires native
`lyricInfo` publication.

## Migration

Bridge keeps its application ID but reduces its scope to `system` and `com.android.systemui`.
Provider application IDs and asset names are new. Old and new Provider APKs can coexist as Android
packages, but must not hook the same player simultaneously.

- [迁移指南](../4.0/MIGRATION-3.8-TO-4.0.zh-CN.md)
- [Migration guide](../4.0/MIGRATION-3.8-TO-4.0.md)

Bridge schema-v3 settings migrate forward. Downgrade is not lossless; create a complete Bridge
backup first.
