# Release v5.1.3 Ledger

Status: **Published on 2026-11-25; independent asset checks passed.** The private RC device gate was waived by the maintainer; no device evidence yet.

## Release scope

- Bridge: 5.1.3, versionCode 154; Bridge tag `v5.1.3` and LSP tag `154-5.1.3`.
- Bridge-only change: DexKit `org.luckypray:dexkit` 2.2.0 → 2.3.0 (PR #85, merged into `main` at `fdf15a020d4a8278538d6f7feb654281f966973e`). Fixes the `com.android.systemui` native `SIGABRT` in `libdexkit.so` during busy boots (#84): with 2.2.0 a query worker could drop the last `QueryScheduler` reference, so `~ThreadPool()` joined its own thread and aborted. Upstream fix: `c3d201f1`, `1d936bd9`.
- Provider store updates in the same period (released independently from the Providers repository): QQ Music Provider 1.2.3 (`player-qq-v1.2.3`) and 1.2.4 (`player-qq-v1.2.4`).
- Providers `main` frozen at `120dc47b6b0fccd0032a21536a0cd53d904004bf` (Providers PR #27 merge).
- Bridge assets: one signed Bridge APK, `release-assets-v5.1.3.json` and `SHA256SUMS`.
