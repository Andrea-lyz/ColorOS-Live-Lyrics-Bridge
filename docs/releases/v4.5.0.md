## User-visible changes
- **ColorOS 17 support** from the C17 previews: native lyric entry, immersive page and row blur,
  typeface/row measurement, translation-action rebinding, KuWo plugin retention.
- **Dynamic artwork** from the Artwork previews, now stable: card and large-cover motion covers,
  C17 mirrored background, artwork-based glow; soft static/motion cross-fades (320 ms in, 220 ms out).
- **Motion cover frame rate** setting 10–30 fps (default 30 = original). Uncapped playback keeps the
  MediaPlayer path; capped playback uses `ArtworkPacedPlayer` (MediaCodec, release-time render
  decision by `ArtworkFramePacer`).
- **Lock-screen performance**: cached keyguard eligibility, translation-scan stall removal, windowed
  char-lift drawing with ligature-safe boundaries. Measurements: `docs/4.0/PHASE-6-PERFORMANCE-LEDGER.md`
  section 8A.
- **Providers**: the 13 dedicated Providers replace their launcher icon with an INFO entry (restart the
  launcher after update; Universal and Artwork keep their launcher entry); Universal
  Provider 1.1.2 opens official players except KuWo (one Provider per player).

## Release pipeline changes
- Bridge contract adds `artworkProviderApkCount = 1`; `totalApkCount = 16`,
  `totalReleaseAssetCount = 19`. The 4.4.0-only `previewUniversalProvider` section was removed;
  `previewArtworkProvider` now pins the 4.5.0 Provider candidate commit.
- `release.yml` verifies the artwork contract mirror, builds/tests/lints `artwork-provider-am` with the
  Provider matrix from the frozen Providers commit, and stages its APK under the contract asset name.
- `build-release-assets.ps1` verifies the artwork APK (package, version, certificate, zipalign, DEX
  guards) and publishes it as a standalone asset, never inside the Provider ZIP.
