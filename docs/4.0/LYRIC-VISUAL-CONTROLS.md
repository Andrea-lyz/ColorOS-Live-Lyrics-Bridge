# Bridge 4.0 歌词亮度与渐隐设置说明

## 设置入口

在 LSPosed 模块设置中打开 **颜色与光晕 → 歌词亮度与渐隐**。本页是下列字段的唯一
可编辑 owner；主页面只显示摘要，避免两处滑块互相覆盖。

- 实时歌词高亮；
- 当前行未高亮部分；
- 实时翻译与翻译进度；
- 非实时正文、翻译跟随/独立亮度；
- RecyclerView 上下边缘渐隐开关与长度；
- 非活动行额外淡化开关与保留百分比。

预览固定在页面上方，使用与 SystemUI renderer 相同的 `LyricUiPalette` 和
`LyricVisualAlphaPolicy`。非实时 value label 中的箭头表示“基础百分比 → row fade 后的
稳态有效百分比”。切歌、handoff、AOD 等临时过渡 alpha 不属于用户配置。

渐隐长度 UI 使用 1dp 步进。旧配置中的 51.9dp 或其他小数值在用户没有触碰该滑块时会
原样保留；首次主动拖动后才规范为整 dp。

## schema v3 默认值

| 字段 | 默认值 |
|---|---:|
| 实时歌词高亮 | 100% |
| 当前行未高亮 | 50% |
| 实时翻译 | 60% |
| 实时翻译进度 | 80% |
| 非实时正文 | 44% |
| 非实时翻译 | 跟随正文；独立保留值 44% |
| 上下边缘渐隐 | 开；51.9dp |
| 非活动行额外淡化 | 关；保留值 90% |

## 预设合同

所有预设都显式写入亮度与渐隐字段，不依赖 blur/scale 隐式决定 row fade。四套预设均保持
100/50/60/80 的实时层级、翻译跟随正文和 51.9dp 上下渐隐；差异如下：

| 预设 | 非实时正文/翻译 | row fade | 其他既有语义 |
|---|---:|---:|---|
| 默认 | 44% | 关；值 90% | 标准光晕，无模糊/缩放 |
| 柔和 | 36% | 开；90% | 轻量模糊、96% 缩放、低光晕 |
| 醒目 | 44% | 开；90% | 强模糊、90% 缩放、完整光晕 |
| 极简 | 55% | 关；值 90% | 关闭光晕、模糊、缩放和动效 |

任一预设管理的颜色、排版、动效、亮度或渐隐字段偏离后，主页面都显示“自定义”。即使
翻译正在跟随正文、row fade 已关闭，dormant value 仍属于预设合同，避免重新打开时出现
来源不明的旧值。

## 升级、全局备份与降级

- v1/v2 升级时保留原 `inactiveOpacityPercent`，并把它作为独立非实时翻译的初值；
- v1/v2 的 row fade enable 按旧 `scaleEnabled || blurEnabled` 推导，升级前后像素不漂移；
- 配置维护不属于本视觉子页。主设置页的独立“Bridge 配置备份与恢复”页面会导出/恢复
  `lockscreen_lyrics` 与 `lockscreen_lyrics_debug` 两个完整配置域，覆盖主 UI、播放器翻译、
  开头清理、调试和设置页语言；
- 备份使用带类型和命名空间的 `Bridge Backup v1` 文本格式；恢复会先完整验证两个配置域，
  写入失败时回滚，并重放 style、player translation、cleanup 和 debug 广播同步 SystemUI；
- 全量重置需要二次确认，并清除全部 Bridge 用户配置；视觉子页不再承载全局备份或重置；
- schema v3 不承诺无损降级。旧 APK 的 codec 可能拒绝 v3 SharedPreferences；降级前先复制
  完整 Bridge 备份留档，必要时在旧版中清除/重置设置后重新配置。

## 不开放的边界

首版不开放 fading-edge strength、handoff/AOD alpha、model reveal 时长、karaoke feather
曲线和 Recycler 几何。它们仍是 renderer 的设备证据常量，避免与系统原生渐隐重复合成或
破坏滚动/AOD 时序。
